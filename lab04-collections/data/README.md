# Входные данные

Внешние файлы и ввод с клавиатуры не требуются. `SampleBooks.create()` создаёт десять книг с постоянными идентификаторами, названиями, авторами и годами. Это учебный набор: даты не следует считать библиографическим описанием конкретного перевода или издания.

Для замера `SearchBenchmark` отдельно создаёт 100 000 книг с идентификаторами 0–99 999, названием `Книга N`, автором `Учебный автор` и годом 2020. В обеих коллекциях находятся одинаковые объекты. Существующая искомая книга — отдельный объект, равный последнему элементу списка; отсутствующая имеет ID 100 000. Создание данных не включено во время поиска.
