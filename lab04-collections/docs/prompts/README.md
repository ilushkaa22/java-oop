### 7. Учебный замер поиска

**Дата:** 09.10.2026.  
**Инструмент:** OpenAI Codex.

**Промпт:**

> Сравни contains в ArrayList и HashSet для 100 000 книг. Исключи создание данных и печать из длительности, добавь прогрев и повторы.

**Результат:** SearchBenchmark создаёт обе коллекции, выполняет 20 поисков прогрева для каждого случая, 100 поисков на измерение и три раунда.

**Критический анализ:** Единичный замер чувствителен к таймеру и JIT. Поиск одного и того же ссылочного объекта в Set не проверяет equals. Короткий прогрев и повтор одного запроса всё равно ограничивают точность.

**Внесённые изменения и причины:** Поиск выполняется для отдельного равного объекта в конце списка и отсутствующего объекта. Порядок коллекций чередуется; число найденных объектов проверяется. Добавлено пояснение, что замер не заменяет JMH.
