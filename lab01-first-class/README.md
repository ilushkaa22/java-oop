### 3. Краткое теоретическое введение

Объектно-ориентированное программирование представляет программу как совокупность взаимодействующих объектов. Класс задаёт структуру и поведение объектов, а объект является конкретным экземпляром класса со своим состоянием. В классе `Book` состояние представлено полями `id`, `title`, `author` и `year`, а поведение — методами чтения, изменения и формирования описания.

Инкапсуляция объединяет данные и работающие с ними методы и ограничивает прямой доступ к внутреннему состоянию. Поэтому поля объявлены с модификатором `private`, а публичные setter-методы контролируют допустимость новых значений. Если значение нарушает правило класса, выбрасывается `IllegalArgumentException`, и объект не переходит в некорректное состояние.

Ключевое слово `this` позволяет явно обратиться к текущему объекту и отличить его поле от одноимённого параметра метода. Для примитивных типов Java предоставляет классы-обёртки, например `Integer` для `int` и `Long` для `long`. Преобразование примитива в объект-обёртку называется автоупаковкой, обратное преобразование — автораспаковкой.

### 5. Листинги программного кода с пояснениями

#### 5.1. Класс `Book`

Класс хранит сведения о книге. Конструктор вызывает setter-методы, поэтому правила проверки данных определены в одном месте. Метод `getDescription()` формирует требуемую строку, а `toString()` использует тот же формат.

```java
import java.time.Year;

/**
 * Представляет книгу с идентификатором, названием, автором и годом издания.
 */
public class Book {
    private long id;
    private String title;
    private String author;
    private int year;

    public Book(long id, String title, String author, int year) {
        setId(id);
        setTitle(title);
        setAuthor(author);
        setYear(year);
    }

    public long getId() {
        return id;
    }

    public void setId(long id) {
        if (id <= 0) {
            throw new IllegalArgumentException(
                    "Идентификатор должен быть положительным");
        }
        this.id = id;
    }

    public String getTitle() {
        return title;
    }

    public void setTitle(String title) {
        if (title == null || title.isBlank()) {
            throw new IllegalArgumentException(
                    "Название не может быть пустым");
        }
        this.title = title;
    }

    public String getAuthor() {
        return author;
    }

    public void setAuthor(String author) {
        if (author == null || author.isBlank()) {
            throw new IllegalArgumentException(
                    "Автор не может быть пустым");
        }
        this.author = author;
    }

    public int getYear() {
        return year;
    }

    public void setYear(int year) {
        int currentYear = Year.now().getValue();
        if (year < 0 || year > currentYear) {
            throw new IllegalArgumentException(
                    "Год должен быть в диапазоне от 0 до " + currentYear);
        }
        this.year = year;
    }

    public String getDescription() {
        return "\"%s\" — %s (%d)".formatted(title, author, year);
    }

    @Override
    public String toString() {
        return getDescription();
    }
}
```

#### 5.2. Класс `Main`

Точка входа создаёт три объекта и выводит их описания с порядковыми номерами.

```java
public final class Main {
    private Main() {
    }

    public static void main(String[] args) {
        Book[] books = {
                new Book(1, "Война и мир", "Толстой Л.Н.", 1869),
                new Book(2, "Мастер и Маргарита", "Булгаков М.А.", 1967),
                new Book(3, "Преступление и наказание",
                        "Достоевский Ф.М.", 1866)
        };

        System.out.println("=== Список книг ===");
        for (int index = 0; index < books.length; index++) {
            System.out.printf("%d. %s%n", index + 1,
                    books[index].getDescription());
        }
    }
}
```

#### 5.3. Модульные тесты

Класс `BookTest` проверяет сохранение корректных значений, работу setter-методов, формат описания и отклонение ошибочных данных. Пример проверки формата и диапазона года:

```java
@Test
void descriptionHasRequiredFormat() {
    Book book = new Book(1, "Война и мир", "Толстой Л.Н.", 1869);

    String expected = "\"Война и мир\" — Толстой Л.Н. (1869)";
    assertEquals(expected, book.getDescription());
    assertEquals(expected, book.toString());
}

@Test
void yearMustBeInAllowedRange() {
    int nextYear = Year.now().getValue() + 1;

    assertThrows(IllegalArgumentException.class,
            () -> new Book(1, "Название", "Автор", -1));
    assertThrows(IllegalArgumentException.class,
            () -> new Book(1, "Название", "Автор", nextYear));
}
```

### 8. Ответы на контрольные вопросы

1. **Что такое класс и объект? В чём их различие?**  
   Класс — описание структуры и поведения сущностей определённого типа. Объект — конкретный экземпляр класса со своими значениями полей. Например, `Book` является классом, а книга «Война и мир» — одним из его объектов.

2. **Какие модификаторы доступа существуют в Java?**  
   `private` разрешает доступ только внутри класса; отсутствие модификатора, или package-private, — внутри пакета; `protected` — внутри пакета и в подклассах; `public` — из любого доступного коду места.

3. **Что такое инкапсуляция? Зачем она нужна?**  
   Инкапсуляция объединяет данные и методы работы с ними и скрывает внутреннее состояние объекта. Она позволяет централизовать валидацию, не допускать некорректных значений и изменять внутреннюю реализацию без изменения клиентского кода.

4. **Чем конструктор отличается от обычного метода?**  
   Конструктор вызывается при создании объекта, имеет имя класса и не объявляет возвращаемый тип. Обычный метод вызывается у уже созданного объекта или класса, имеет произвольное допустимое имя и объявленный возвращаемый тип, включая `void`.

5. **Для чего используется ключевое слово `this`?**  
   `this` ссылается на текущий объект. Оно позволяет обращаться к его полям и методам, различать поле и одноимённый параметр, а также вызывать другой конструктор того же класса через `this(...)`.

6. **Что такое классы-обёртки? Что такое автоупаковка?**  
   Классы-обёртки представляют примитивные значения как объекты: например, `Integer`, `Long`, `Double` и `Boolean`. Автоупаковка — автоматическое преобразование примитива в соответствующую обёртку, а автораспаковка — обратное преобразование.

7. **Почему прямой доступ к полям класса считается плохой практикой?**  
   Прямой доступ не позволяет классу контролировать изменения состояния. Setter-метод может проверить значение, сохранить инварианты объекта и скрыть детали внутреннего представления.

8. **Какие преимущества даёт ООП по сравнению с процедурным программированием?**  
   ООП помогает моделировать предметную область через объекты, разделять ответственность между классами, скрывать детали реализации и повторно использовать код. Это упрощает сопровождение и развитие крупных программ, хотя для небольших линейных задач процедурный подход может быть проще.
