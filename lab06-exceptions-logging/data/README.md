# Входные данные

Запускать программу из корня `lab06-exceptions-logging`.

`books.txt` — UTF-8, одна книга на строку, формат `title;author;year`, без заголовка и без экранирования разделителя внутри полей. Это простой учебный формат, а не полноценный CSV.

В файле шесть строк: три корректные книги и три ошибки (пустое название, нечисловой год, недостаточное количество полей). После отклонения строки чтение продолжается. Пустая строка тоже считается ошибкой формата.

Путь к другому файлу можно передать первым аргументом программы. Дополнительная попытка открыть `data/missing-books.txt` демонстрирует обработку отсутствующего файла: этот файл намеренно не включён в проект.

Репозиторий работает в памяти. Успешно прочитанные строки сохраняются сразу; отката всей загрузки при последующей ошибке нет.
